# 序言 · 最小 Agent 服务

现有群聊页面通过同源 `POST /api/chat` 调用 DeepSeek V4.1 Flash（`deepseek-flash`）。密钥只在服务端使用，浏览器不直接访问供应商。无需第三方 npm 依赖，要求 Node.js 22.9+。

## 本地运行

复制 `.env.example` 为 `.env`，填写 `DEEPSEEK_API_KEY`，然后运行 `npm start`，打开终端打印的 `http://127.0.0.1:4173`。本地服务仅监听回环地址，不需要登录。仅用静态服务器或直接打开 HTML 无法调用 Agent。

`.env` 已被 Git 忽略，不能复制到 `dist/` 或提交。生产环境通过 Sites Secret 配置 `DEEPSEEK_API_KEY`，普通运行变量为 `DEEPSEEK_MODEL=deepseek-flash`。

## 当前能力与边界

- 新消息得到真实模型回复；按当前项目传入标题、统一上下文和最近最多 18 条成功对话记录。失败请求不进入模型历史，可点击重试。同一项目一次处理一条请求，切换项目不串用回复，开启新对话会取消当前请求并清空本轮历史。
- 模型输出按纯文本转义显示，保留换行；初始示例快照仍可展开与切换，并标注“示例快照”。新回复不伪造快照或缓存命中。
- 项目、成员和上下文仍为本次页面会话内状态，刷新会重置；没有数据库、自动摘要、长期记忆、真实成员授权、业务工具或真实快照生成。
- 生产接口要求 Sites 转发的已登录用户身份，访问范围由平台访问策略控制。当前仅面向站点所有者私有使用；模拟成员名单不是服务端项目权限。
- 请求体上限 100 KB，上下文最多 10,000 字符，单条消息最多 6,000 字符，输出最多 1,500 tokens；默认关闭思考模式。服务端超时 45 秒，浏览器超时 55 秒。
- 每个运行实例内每位用户最多 20 次/分钟、同时最多 2 次请求。这是轻量限流，不能充当跨实例硬预算。上线多人使用前应补齐持久配额、服务端项目权限和存储。
- Key 失效、欠费、限流、网络错误、空回复和超时都有明确提示；上游错误正文和密钥不会返回浏览器。

## 构建和发布

运行 `npm test` 和 `npm run build`。

`server/api.mjs` 是本地与云端共用的模型代理。`server/local.mjs` 仅用于本地开发，静态路由使用明确白名单。

`scripts/build.mjs` 把指定公开资源和代理打包到 Cloudflare Worker 兼容的 `dist/server/index.js`，生成 `dist/.openai/hosting.json`；不读取 `.env`。通过 Sites 发布 Worker；修改运行环境变量后重新部署才能生效。

验收：生产域名能打开页面；登录后通过 `/api/chat` 得到真实回复；未登录不能消费模型额度；生产请求不依赖本机进程；静态资源和归档不包含密钥。

产品目标见 `PRD.md`，快照协议见 `docs/SNAPSHOT_SPEC.md`；这些后续目标并不代表本版已实现。
