# Phase 2 最小项目聚合 · 本地实现与测试记录

日期：2026-09-27。状态：代码及本地自动化通过；真实 DAO 多员工与 DeepSeek/Timeline 新链路手工回归待完成。不能据此宣布生产发布。

## 实现范围

- Node 正式入口默认加载真实项目页面；演示页面仅限非生产显式 `XUYAN_DEMO_UI=true`，生产静态路由拒绝 dummy 快照资源。
- 项目仓库以服务端 UUID 建立一个文件一个项目的聚合，用 AES-256-GCM 加密名称、上下文、共享文字对话及 actor 元数据。原子写入、项目删除一并删除上下文与对话。开发目录默认 `.local/projects`；生产必须显式提供 `PROJECT_DATA_DIR` 和 32 字节 base64 `PROJECT_ENCRYPTION_KEY`。
- 项目 API 以 BFF session 为身份，首发所有已登录员工同权。聊天入口只读取服务端项目 ID、上下文、历史消息及真实 actor；客户端提交的项目名称／上下文／历史会被忽略。相同幂等键与不同消息冲突返回 409；同项目 Agent 运行时暂拒修改和并发运行。
- 快照包仍仅随本次响应返回页面并由隔离 viewer 校验；共享文字消息保存，刷新后原快照包无法回放，页面有明确说明。
- 本地 `XUYAN_MOCK_OAUTH=true` 提供需点击的模拟登录页，建立正常 HttpOnly session；生产模式配置校验拒绝该开关，模拟路由不可用。原真实 DAO OAuth 实现不变。

## 已运行检查

- `npm run check`：57 项 Node 测试通过，构建通过，7 个 dummy fixture 校验通过。覆盖加密文件不含明文、重启恢复、密钥错误拒绝、项目删除、跨员工共享、客户端上下文伪造无效、文字对话保存、幂等冲突、归档与清空对话、未登录与跨站拒绝、本地 mock OAuth 点击流程及生产拒绝 mock。
- `npm run test:e2e`：Chromium/WebKit 共 34 项通过。新增正式页面测试覆盖创建项目、编辑上下文、刷新恢复及删除；既有 32 项 fixture 和聊天/快照回归保留在显式演示模式。
- 本地 4174 服务以 `XUYAN_MOCK_OAUTH=true` 启动，未登录 `/api/session` 返回 401；模拟登录链路 HTTP 状态为登录 302 → 模拟页 200 → 回调 302 → session 200 → 项目列表 200。仅核验状态，不输出 cookie 或项目正文。本轮仍等待用户手工点击登录及真实项目交互验收。

## 尚未验证及发布阻断

- 尚未使用两个真实 DAO 员工账号对同一项目进行跨浏览器读写和真实 Agent 对话回归；本地 mock 不能代替此项。
- 尚未对新服务端聚合链路重跑真实 DeepSeek→Timeline 读取／快照，也未实测真实 change-set 写入；不得把旧演示壳的验收等同于新链路验收。
- 文件仓库只适用于单实例持久卷；阿里云持久卷、备份恢复、密钥托管和数据库／多实例迁移未验收。`.development-key` 丢失会令开发数据不可恢复，生产密钥同理。
- 已知宿主工具秘密脱敏、私网访问和审计 actor 阻断项仍在 Phase 4A；共享问答缓存未实现。快照包、快照历史及生成运行记录未持久化。
